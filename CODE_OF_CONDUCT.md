# Code of conduct

Tab5 OS contributors and maintainers must keep project spaces respectful, technically honest, and safe for people of different backgrounds and experience levels.

Expected behavior includes constructive review, clear evidence, credit for others' work, respect for privacy, and patient disagreement about engineering tradeoffs. Unacceptable behavior includes harassment, threats, discriminatory language, sexualized attention, doxxing, publishing private communications or credentials, deliberate hardware-safety misinformation, and sustained disruption.

Project maintainers may edit or remove contributions and restrict participation when behavior violates these expectations. Report conduct concerns privately through the repository owner's GitHub profile or, when confidentiality/security overlaps, the process in [SECURITY](SECURITY.md). Reports will be considered on their evidence and context while protecting affected people as far as practical.

This policy applies in repository discussions, reviews, project communication, and public representation of the project.
